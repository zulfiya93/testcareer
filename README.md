# Профориентация (RIASEC) — 8–9 сынып

Ванильді **HTML/CSS/JS** негізіндегі профориентациялық веб-сайт (Holland RIASEC).

## Қалай іске қосу

Бұл жоба статикалық. Екі жол:

- **Ең оңайы**: `index.html` файлын браузермен ашыңыз.
- **Ұсынылатын**: локал сервер (кейбір браузерлер `fetch` үшін керек болуы мүмкін).
  - VS Code / Cursor → Live Server extension
  - немесе кез келген статикалық сервер

## Негізгі мүмкіндіктер

- Қазақ/орыс тілдері
- RIASEC тесті (балл жинау → dominant code, мысалы `IAS`)
- Нәтиже беті: типтер түсіндірмесі, қызығушылық картасы, мамандық/оқу орындары ұсынысы
- Нәтижені PDF ретінде сақтау (браузердің Print → Save as PDF)
